# Type Checking

# Git hook framework
# Declared explicitly on purpose: HA Core does NOT ship pre-commit. As of
# Current HA test requirements pin `prek` (a Rust reimplementation)
# instead, so relying on HA to provide the hook framework silently left
# `pre-commit install` failing in script/setup/bootstrap and no hooks
# installed at all. .pre-commit-config.yaml targets pre-commit, so the
# blueprint owns this dependency itself.
pre-commit==4.6.1

# Better logging for development scripts
colorlog==6.12.0

# Performance optimizations (optional but recommended for faster development)
# These speed up Home Assistant's startup and runtime
zlib_ng==1.0.0
